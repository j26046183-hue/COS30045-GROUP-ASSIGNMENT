# Australian Road Safety Enforcement Dashboard

An interactive data visualisation dashboard exploring 16 years (2008–2024) of Australian road safety enforcement data — covering fines, drug testing and breath testing across all 8 states and territories. Built using D3.js as part of COS30045 Data Visualisation.

## Team
- Kartikyogam
- Kugendran

## Live Site
https://mercury.swin.edu.au/cos30045/s106413154/Group10/index.html

## Data Source
Bureau of Infrastructure and Transport Research Economics (BITRE), 2024.

## Pages
- **Home** — Dataset overview, key enforcement statistics, data governance notes
- **Fines** — Road fines by state, age group, offence type and location
- **Drug Tests** — 16-year drug testing trends, drug type breakdown, state enforcement actions
- **Breath Tests** — 16-year breath testing trends, location and age profile breakdowns

## Tech Stack
- D3.js v7 — data visualisation
- HTML / CSS / Vanilla JavaScript
- KNIME — data cleaning and preprocessing
